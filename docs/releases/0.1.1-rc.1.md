# SwiftVoice 0.1.1-rc.1

Release candidate for Windows x64. This build addresses the 17 application
review findings. Recognition accuracy on the user's English dictation is
still an open validation item; this candidate does not claim to resolve it.

## Changes

- Preserve speech retained after a forced audio cut and structural newline commands.
- Serialize paste transactions, keep all dictation out of clipboard history,
  and retain failed output for a deliberate clipboard retry.
- Bound the recognizer backlog and keep model/runtime settings from
  invalidating pending dictation.
- Reload the speech detector after installation, preserve cancellation
  while shortcuts change, and reset all three shortcuts atomically.
- Expose shortcut instructions and errors through native accessible controls.
- Support document editors that expose TextPattern without ValuePattern.
- Keep a custom configuration path at Windows sign-in.
- Route CLI language fallback consistently and keep server response bodies
  out of ordinary logs.

## Compatibility

Windows 10/11 x64. The packaged Whisper fallback requires an AVX2-capable
CPU; its build does not select additional features from the build machine.

Language settings accept `auto` or two-letter ISO 639-1 codes. Change `eng`
to `en`, for example. Existing valid two-letter settings continue to work.
Clipboard fallbacks pause queued output: paste the current text, then press
the dictation shortcut for the next retained phrase.

## Install and rollback

Extract the whole zip into a new folder. Quit the previous SwiftVoice
instance before starting the candidate. Keep the runtime DLLs beside the
executable; models are downloaded separately. Use `.\swiftvoice.com --doctor`
from that folder to check the installation.

Keep the previous application folder and a copy of your configuration.
To roll back, quit the candidate and start the previous executable. If you
changed settings while testing, restore your saved configuration too.

## Validation still required

Test a failing English recording against the direct recognizer and live
dictation, then compare noise suppression and the English-only Parakeet v2
model one change at a time. No model or accuracy settings are changed
automatically in this candidate.

Live microphone, target-application insertion, clipboard history, Narrator,
hotkeys and sign-in checks remain manual. Current executed checks are in
`docs/TESTING_EVIDENCE.md`; the full checklist is `tests/MANUAL_TESTS.md` in
the source repository. Promote to a stable release after these checks and
the reported accuracy issue have been evaluated.
